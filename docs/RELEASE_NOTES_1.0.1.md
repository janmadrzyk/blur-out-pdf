# BlurOut PDF 1.0.1

BlurOut PDF is a local Windows viewer for PDFs and raster images. It lets you mark rectangular areas and save a rewritten document or image with those areas covered. PDF search, page export, raster conversion, metadata editing, Polish and English interfaces, and light/dark appearance are included.

Version 1.0.1 is the first public release; 1.0.0 was an unpublished test candidate. It restores Windows **Open with** integration for PDFs and supported raster formats and makes the dragged selection marquee visible in the file picker.

The black cover is the safer choice for sensitive content. Blurred covers can retain visual clues. Check every saved file, including repeated content elsewhere in a document, before sharing it.

Embedded PDF text search works without OCR. Search on scanned pages requires compatible OCR language data already available on the computer; the installer does not provide or download models.

The installer is unsigned. Windows may display a Microsoft Defender SmartScreen warning that the publisher is unknown. This means Windows has no established publisher reputation for the installer; it is not a finding that the file is malicious. Download the installer and `SHA256.txt` from the [official GitHub release](https://github.com/janmadrzyk/blur-out-pdf/releases/tag/v1.0.1) and verify the checksum before running it. The [public source repository](https://github.com/janmadrzyk/blur-out-pdf) includes the release checklist and license notices.
