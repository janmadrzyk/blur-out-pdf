# BlurOut PDF 1.0.1 — release notes draft

BlurOut PDF is a local Windows viewer for PDFs and raster images. It lets you mark rectangular areas and save a rewritten document or image with those areas covered. PDF search, page export, raster conversion, metadata editing, Polish and English interfaces, and light/dark appearance are included.

Version 1.0.1 supersedes the unpublished 1.0.0 candidate and permits an in-place upgrade from that test version. This candidate prepares fixes for missing Windows **Open with** integration and the invisible dragged selection marquee in the file picker. Their verification status is recorded in [the release checklist](ISSUES.md).

The black cover is the safer choice for sensitive content. Blurred covers can retain visual clues. Check every saved file, including repeated content elsewhere in a document, before sharing it.

Embedded PDF text search works without OCR. Search on scanned pages requires compatible OCR language data already available on the computer; the installer does not provide or download models.

The [public GitHub repository](https://github.com/janmadrzyk/blur-out-pdf) is available. This installer remains a candidate until clean-Windows lifecycle and application acceptance checks pass for the exact CI artifact and its checksum. No public 1.0.0 software release was published.
