# BlurOut PDF

BlurOut PDF is a small, offline Windows document viewer for PDFs and raster images, focused on drawing rectangular redactions and saving a shareable copy.

![BlurOut PDF showing a pending redaction in dark mode](docs/assets/ui-preview.png)

The screenshot uses a synthetic PDF generated by [the preview script](scripts/capture_preview.py). No user document is included in the repository.

## Current features

- Open regular and password-protected PDFs; scroll through pages continuously or use single-page mode.
- Open raster images in JPEG/JPG, PNG, TIFF, BMP and WebP formats. Multi-page TIFF files appear as a sequence of pages.
- Draw an area with the left mouse button while **Redact** is active. The selection is pending until saved.
- Undo the last pending redaction with Ctrl+Z. Text search is disabled while a raster image is active.
- Save or Save as a fully rewritten PDF. Text intersecting the area is removed with PyMuPDF redactions; overlapping image pixels and vector content are removed. On a redaction save, the exporter also strips common hidden data, including metadata, embedded files, JavaScript, links and form responses.
- Save a raster image in its current format or use **Save as** to convert it to another supported raster format. A single-image **Save as** switches the open tab to the new file. Saving rewrites the pixels under each redaction and strips source image metadata, including EXIF data. Converting a multi-page TIFF to PNG, JPEG, BMP or WebP creates numbered files in a separate folder; the TIFF stays open with its pending changes intact.
- Choose black or a blurred cover style. Blurred styles are derived from the source image and can retain visual clues; black is the safest option for sensitive content.
- Export PDF pages as raster images at a fixed 200 DPI. Multi-page PNG, JPEG, BMP and WebP exports are numbered files in a dedicated folder; TIFF is written as one multi-page file.
- Rotate pages, search text, navigate pages, and control zoom from the percentage box and slider.
- Search text embedded in PDFs without OCR. For scanned pages, optional OCR uses compatible Tesseract language data already present on the computer.
- Polish on Polish systems; English elsewhere. Language can be changed in Settings. The UI follows the operating system's light/dark theme, including changes while the app is open.

## Optional OCR for scanned PDFs

Search of text already embedded in a PDF works without OCR. Pages containing only an image, or text with a damaged character mapping, need OCR to become searchable. OCR availability depends on compatible local Tesseract support and language data, so it can differ between computers. A clean Windows installation is not guaranteed to have it. Normal PDF viewing, raster viewing and embedded-text search still work when OCR is unavailable.

The installer does not include or download OCR language models. To enable OCR independently, install compatible Tesseract support and put `eng.traineddata` in its `tessdata` directory. The app checks for this file next to its code, in the directory named by `TESSDATA_PREFIX`, and in supported Windows Tesseract data locations. Set `TESSDATA_PREFIX` to the directory containing `eng.traineddata` if it is elsewhere. For example, before launching from PowerShell:

```powershell
$env:TESSDATA_PREFIX = "C:\Program Files\Tesseract-OCR\tessdata"
```

In **Settings > OCR language**, **System default** selects the Windows UI language plus English. If the chosen language model is missing but English is available, OCR falls back to English. The menu lists locally available models and keeps a manually selected missing model visible so it can be changed. A permanent message in the bottom status bar reports a missing English model or a fallback from the selected language. Language model filenames use three-letter codes such as `pol.traineddata`; additional models belong in the same directory as `eng.traineddata`. Restart the app after adding models or changing `TESSDATA_PREFIX`.

## Supported files

| Input | Save and export |
| --- | --- |
| PDF | Save as PDF; export pages as PNG, JPEG, TIFF, BMP or WebP images. |
| JPEG/JPG, PNG, TIFF, BMP, WebP | Save in the current format or convert with **Save as**. Multi-page TIFF can also be split into numbered images. |

Text search works only in PDFs. Scanned pages need locally available OCR support, as described above.

## Run from source

Requires Python 3.11+ on Windows.

```powershell
uv venv .venv
$env:UV_CACHE_DIR = "$PWD\.uv-cache"
uv pip install --python .venv\Scripts\python.exe -e ".[dev]"
.venv\Scripts\python.exe run.py
```

Open a file directly with `.venv\Scripts\python.exe run.py C:\path\to\file.pdf` (or a supported raster image). The installer adds BlurOut PDF to Windows **Open with** for PDF and supported raster extensions without changing the default app.

## Verify

```powershell
.venv\Scripts\python.exe -m pytest -q --basetemp=.pytest-temp
```

The tests reopen saved PDFs and confirm that redacted text and common hidden data are gone. They also check rotation and the main window flow.

## Build a Windows installer

Install [Inno Setup](https://jrsoftware.org/isinfo.php), then run:

```powershell
.\packaging\build.ps1
```

This produces `dist\BlurOutPDF-Setup-1.0.0.exe`. The installer registers BlurOut PDF as an **Open with** option for PDFs and all supported raster formats without taking over their default viewer. The executable, installer and application window use the transparent icon derived from the supplied draft. The version comes from `src/blurout_pdf/_version.py` and is passed to both Windows build tools. See the [1.0.0 release notes](docs/RELEASE_NOTES_1.0.0.md) and [changelog](CHANGELOG.md).

## Privacy and security scope

BlurOut PDF works locally and makes a fresh PDF when saving. The old source file is overwritten only if you choose **Save**; **Save as** creates another file. The exporter removes objects referenced solely by the redacted area and verifies that no extractable characters intersect each selected rectangle in the output.

PDFs can contain duplicate sensitive data elsewhere, including visible text on another page. Complex interactive PDF features and malformed PDFs need further validation before relying on the result for high-stakes disclosure. Review the saved file, especially all pages and any repeated information, before sending it. The current exporter removes links, embedded files, metadata and form responses when saving redactions. See [technical specification](docs/SPEC.md) for boundaries and planned work.
